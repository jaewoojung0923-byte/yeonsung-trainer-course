# 연성대학교 트레이너 교육과정 소개 페이지

BASIC → ADVANCE 트레이너 교육과정 소개용 단일 페이지 정적 사이트입니다.
외부 리소스 없이 순수 HTML/CSS(인라인)로만 작성되어 있어 별도 빌드 과정 없이 그대로 배포할 수 있습니다.

## 구성

- [`index.html`](index.html) — 배포용 페이지 (GitHub Pages가 서빙하는 파일)
- [`claude/page-v1.html`](claude/page-v1.html) — 작업용 원본 소스 (내용 수정은 이 파일을 기준으로 하고, 이후 `index.html`에 복사)
- [`claude/강의-컨텍스트.md`](claude/강의-컨텍스트.md) — 확정된 표기 규칙 및 남은 빈칸(플레이스홀더) 체크리스트

## 로컬에서 미리보기

별도 서버 없이 `index.html`을 브라우저로 바로 열어도 되고, 로컬 서버로 띄우려면:

```bash
npx serve .
```

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 푸시합니다.
2. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`로 선택하고,
   브랜치는 `main`(또는 배포용 브랜치), 폴더는 `/ (root)`로 지정합니다.
3. 저장 후 몇 분 내로 `https://<사용자명>.github.io/<저장소명>/` 주소에서 페이지를 확인할 수 있습니다.

## 남은 작업

콘텐츠 중 아직 확정되지 않은 항목(과정명, 강사 정보, 기수 일정, 정식 명칭, 대표 이메일, 수료증 발급 주체 등)은
페이지 내 점선 테두리 + 주황색 텍스트("입력 필요")로 표시되어 있습니다.
자세한 목록은 [`claude/강의-컨텍스트.md`](claude/강의-컨텍스트.md)의 체크리스트를 참고하세요.
